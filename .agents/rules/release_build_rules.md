# قواعد بناء وتوزيع التحديثات وحزم التطبيق (R8 Release & Optimization)

## 📌 الالتزام الدائم والمستمر:
1. **صيغة وبناء التحديثات**:
   - يتم دائماً وبشكل إلزامي بناء النسخ الموجهة للمستخدمين والتحديثات بنظام وتقنية **R8** الكاملة المصغرة والموقعة.
   - تفعيل `isMinifyEnabled = true` و `isShrinkResources = true` لتقليص استهلاك الموارد وحجم التطبيق للمستخدمين إلى الحد الأدنى (~5.9 MB).
2. **التوقيع الرقمي**:
   - الحزمة يجب أن تكون موقعة (`signingConfig`) لضمان تثبيتها التلقائي والمباشر لدى جميع المستخدمين دون أخطاء الشهادات.
3. **نشر التحديث اللحظي**:
   - حساب بصمة SHA-256 الدقيقة وحجم الملف بالبايتات وتحديث ملف `update.json` على الفرع الرئيسي `main`.
   - توجيه التحديث إلى الرابط المباشر لحزمة `app-release.apk` المصغرة.
